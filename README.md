# 📦 Домашнее задание №16: Методы `call`, `apply`, `bind`

##  Описание
Проект демонстрирует практическое применение методов заимствования контекста в JavaScript. На основе объекта `ToDoList` из предыдущего домашнего задания реализовано последовательное применение его методов к новому объекту `newTask` с использованием `.call()`, `.apply()` и `.bind()`.

##  Технологии

- CSS3 (CSS Variables, Flexbox)
- Vanilla JavaScript (ES6+)
- Git & GitHub

## 🎯 Ключевые концепции
- **Заимствование методов (Method Borrowing)** — использование функций одного объекта в контексте другого без дублирования кода.
- **Управление `this`** — явная привязка контекста выполнения.
- **Различия методов**:
  - `.call(context, arg1, arg2)` — вызов сразу, аргументы перечисляются через запятую.
  - `.apply(context, [args])` — вызов сразу, аргументы передаются массивом.
  - `.bind(context, arg1, arg2)` — возврат новой функции с зафиксированным контекстом, вызов отложенный.
- **Адаптация структур данных** — преобразование полей объекта под требования заимствуемых методов.

### Исходные данные
Объект `newTask` взят из условия преподавателя:
```javascript
const newTask = {
  tasks: [{ id: 1, name: 'тест', description: 'описание', order: 0 }],
  nextId: 2
};

Методы ToDoList ожидают поля title и priority, поэтому перед применением реализована функция-адаптер adaptStructure(), которая преобразует name → title и order → priority.
